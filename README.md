# 1.Sum of Even Numbers

A simple Python program that calculates the sum of all even numbers from 1 to `n` using a loop and an `if` statement.

### Features

* Uses a `for` loop
* Checks even numbers using `if`
* Calculates the sum without using `sum()`
* Counts the number of even numbers

# 2.Stone Paper Scissors

A simple Python program that lets the user play Stone-Paper-Scissors against the computer.

### Features

User selects Stone, Paper, or Scissor.
Computer randomly selects an option.
Determines the winner based on the game rules.
Displays both choices and the result.
